# Store 应用商店使用说明

Store 用于浏览 LILYGO UI 应用目录，安装、更新和移除设备上的应用。
安装所需的系统依赖由设备配置的 APT 软件源提供。

## 使用前准备

- 设备上已安装完整的 `lilygo-ui-store` 软件包及其授权策略。
- 网络能够访问应用目录、软件下载地址和系统 APT 软件源。
- 预留下载、解包及依赖安装所需的存储空间。
- 应用与设备架构及 AppKit 版本兼容；不兼容条目会显示不可用状态。

## 浏览和安装

1. 从 Launcher 打开 **Store**。
2. 在应用目录选择 **All**、**Official** 或 **Community** 筛选来源。
3. 点击应用条目查看介绍、作者、版本、体积和截图等详情。
4. 点击列表中的 **Get**，或详情中的 **Get App**。
5. 等待下载与安装完成。安装时会检查大小、SHA-256 和软件包身份，并安装所需系统依赖。
6. 回到 Launcher，等待图标刷新后打开新应用。

安装进行中显示 **Working...**，不要重复提交同一操作。
若系统出现授权请求，按设备现有授权方式完成；商店不会替你创建管理员凭据。

## 更新应用

1. 打开已安装应用列表，查看带 **Update** 的条目。
2. 点击 **Update**，或进入详情后点击 **Update App**。
3. 等待成功状态；发生错误时查看详情中的错误信息再重试。

更新会保留既有系统配置文件。依赖解析失败时，商店不会绕过 APT 强行安装。
商店目录不是 APT 软件源，应用间的依赖不会自动从目录中另外下载安装。

### 更新 Launcher

已安装的 Launcher 可以作为受保护系统组件更新。
更新交给设备的独立更新服务后，Store 会退出，Launcher 随后重启。
较旧镜像若不含 Launcher 更新辅助程序，需要管理员先完成一次基础升级。
Store 不提供首次安装 Launcher 或移除 Launcher 的操作。

## 移除应用

在应用详情使用 **Delete App**，或使用已安装列表的移除入口。
这是卸载软件包操作；需要保留的数据请先按该应用的文档确认位置。
Store 自身和 Launcher 均受保护，不能在此移除。

当前代码中，已安装条目的 **Open** 会进入详情，详情中的 **Open App** 不执行启动。
要运行应用，请返回 Launcher 点击图标。

## 缓存与权限

已验证的应用目录缓存在 `$XDG_CACHE_HOME/lilygo-ui-store/registry/`；
未设置 XDG 缓存目录时使用 `$HOME/.cache/lilygo-ui-store/registry/`。
再次打开时可以先显示缓存目录，同时联网刷新；看到旧目录不代表下载和安装可离线完成。

软件包安装调用受授权的安装辅助程序，卸载通过系统软件包管理工具执行。
默认目录地址由应用配置；管理员可通过 `LILYGO_UI_STORE_REGISTRY_URL` 指定兼容的 HTTPS 镜像。
镜像地址必须以 `/v1/root.json` 结尾。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 应用目录加载失败 | 检查网络与系统时间，使用 **Retry**；目录验证失败时不会显示不完整的新目录。 |
| **Not Compatible** / **Unavailable** | 核对设备架构、系统与 AppKit 要求，使用适配该设备的软件包。 |
| 下载或校验失败 | 检查网络与磁盘空间后重试，不应跳过摘要校验。 |
| 依赖无法安装 | 检查设备 APT 源及错误中列出的依赖；目录本身不提供 APT 仓库。 |
| 授权失败 | 检查完整包、polkit/授权环境和当前账号权限。 |
| 更新后桌面没有变化 | 回到 Launcher 等待刷新；核对已安装列表中的版本。 |
