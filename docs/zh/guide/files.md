# Files 文件管理使用说明

Files 用于管理一个指定根目录内的文件和文件夹。
设备默认根目录为当前用户主目录，不能通过界面向上跳出该根目录。

## 使用前准备

- 从 Launcher 打开 **Files**。
- 需要浏览的文件应位于应用根目录下；普通设备通常是当前账号的主目录。
- 文件操作需要当前用户对源文件及目标目录具有相应权限。
- 模拟器默认浏览项目内的 `simulated-home/`，与设备上的真实主目录不同。

## 浏览、搜索与预览

1. 点击文件夹进入，使用导航栏返回按钮回到上级文件夹。
2. 点击支持的文本文件，查看只读预览。
3. 点击 **Search** 输入文件名，在当前文件夹中筛选。
4. 打开右上角 More 菜单，选择 **Icons** 或 **List** 切换显示方式。
5. 同一菜单可按 **Name**、**Kind**、**Date** 或 **Size** 排序。

搜索不会递归扫描子文件夹。文本预览最多约 8 KiB，不能编辑文件。
不支持的文件类型会提示无法预览，文件仍保留在原位置。

## 复制、移动和整理

| 操作 | 步骤 |
| --- | --- |
| 新建文件夹 | 在 More 菜单选择 **New Folder**，输入名称。 |
| 复制 | 长按条目选择 **Copy**，进入目标文件夹，在 More 菜单选择 **Paste**。 |
| 移动 | 长按条目选择 **Move**，在目标选择界面选定文件夹并完成操作。 |
| 重命名 | 长按条目选择 **Rename**，输入新名称。 |
| 查看信息 | 长按条目选择 **Get Info**。 |
| 创建副本 | 长按条目选择 **Duplicate**。 |
| 压缩 | 长按条目选择 **Compress**，创建 ZIP 压缩包。 |
| 删除 | 长按条目选择 **Delete**，确认后永久删除。 |

重命名和移动不会覆盖已存在的同名条目。
删除没有回收站或撤销功能，请在确认前核对选择。

## 批量操作

1. 在 More 菜单选择 **Select**。
2. 点击条目选择或取消选择，**Select All** 选择当前可见的全部条目。
3. 使用底部工具栏复制副本、移动或删除；工具栏菜单提供复制、放入新文件夹和压缩为一个 ZIP。
4. 完成后点击 **Done**。

搜索结果和选择模式中的长按不会弹出普通单项菜单。
不提供分享、标签或收藏功能。

## 键盘操作与内置帮助

- `Tab` 在控件之间移动焦点；方向键在文件集合内移动。
- 图标视图的上下键按视觉行移动，列表视图按条目移动。
- 短按 `Enter` 打开条目；长按 `Enter` 打开条目操作菜单。
- `Esc` 关闭当前菜单。搜索框支持键盘输入与 Backspace。
- 在 More 菜单打开 **Help** 查看内置说明；关闭后保留目录、搜索和滚动状态。

## 更改可访问目录

管理员可在启动前指定绝对路径：`lilygo-ui-files --root=/path/to/folder`。
也可设置 `LILYGO_UI_FILES_ROOT`，或在用户配置
`$HOME/.config/lilygo/ui/files.conf` 写入 `files.root=/absolute/path`。
设置 `XDG_CONFIG_HOME` 时，用户配置位于其下的 `lilygo/ui/files.conf`。
系统默认配置是 `/etc/lilygo/ui/files.conf`。

优先级依次为命令行、环境变量、用户配置、系统配置、默认目录。
配置只改变浏览范围，不赋予新的文件系统权限。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到收到的文件 | 在当前登录账号的 `Downloads` 中查找，并确认 Files 根目录包含该位置。 |
| 搜索没有结果 | 搜索仅作用于当前目录，先进入文件所在目录。 |
| 无法复制或移动 | 检查权限、可用空间与目标同名文件。 |
| 无法预览 | 确认是支持的文本文件；二进制文件及符号链接存在限制。 |
| 删除后找不到恢复入口 | 当前实现永久删除，不提供回收站恢复。 |
