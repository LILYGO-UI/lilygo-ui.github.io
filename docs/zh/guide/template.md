# Template 计数器演示使用说明

Template 是应用开发模板随附的计数器演示。
它用于体验一个最小应用的操作和布局，不是设备管理工具。
安装后的示例程序名为 `lilygo-ui-template`。

## 使用前准备

- 系统已安装 Template 示例及其共享字体依赖。
- 使用支持触摸或指针点击的显示环境。
- 不需要传感器、串口设备、账户或网络连接。

开发者从模板创建的新应用可能已更名并替换界面。
本页仅描述未修改的 Template 计数器示例。

## 打开与操作

1. 在已安装示例的 Launcher 中打开 **Template**。
2. 找到页面中间的 **Counter** 卡片。
3. 初始数值为 `0`，点击 **+** 增加到 `1`。
4. 再点 **+** 可继续累加，每次增加 `1`。
5. 点击 **-** 每次减少 `1`。
6. 点击 **Reset** 立即回到 `0`。

| 控件 | 效果 |
| --- | --- |
| `+` | 加 1，上限为 999。 |
| `-` | 减 1，下限为 0。 |
| `Reset` | 将数值清零。 |

到达边界后继续点击不会溢出：0 不会减为负数，999 不会继续增加。
重置没有额外确认步骤，只改变当前演示计数。

## 体验屏幕适配

在桌面窗口中调整窗口大小，或在支持的设备上改变屏幕方向。
卡片和按钮间距会根据可用宽度调整。
不需要在应用中寻找横屏、竖屏或紧凑模式开关。
只改变布局不会重置正在运行的计数器。

## 一个简短的验证流程

1. 打开示例，确认数值为 `0`。
2. 点击 **+** 三次，确认显示 `3`。
3. 点击 **-** 一次，确认显示 `2`。
4. 调整窗口尺寸，确认数值仍为 `2` 且控件可操作。
5. 点击 **Reset**，确认显示 `0`。
6. 再点击 **-**，确认仍为 `0`。

这个流程验证当前界面的计数和响应，不代表已验证任何硬件功能。

## 数据与退出

计数仅存在于当前应用实例的内存中，没有文件保存或导出功能。
退出并重新启动后，从 `0` 开始。
没有登录、设置页面、历史记录或后台计时功能。
直接关闭桌面窗口或使用系统提供的应用退出方式结束示例。

## 常见问题

| 现象 | 说明 |
| --- | --- |
| Launcher 中没有 Template | 这是开发示例，不保证随正式系统镜像安装。 |
| 应用名称或界面不同 | 开发者可能已基于模板替换实现，本页操作不再适用。 |
| 数值到 999 后不再增加 | 已到达示例定义的最大值。 |
| 重开后计数消失 | 示例不保存计数，是当前实现的预期行为。 |

本文依据本地 Template 的 Counter 页面、Model 和 ViewModel 实现整理。
需要以模板开发应用，请查看文档中心中的开发文档。
