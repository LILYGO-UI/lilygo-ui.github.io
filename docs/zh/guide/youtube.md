# YouTube 使用说明

YouTube 直接访问 YouTube 接口和 CDN 解析公开视频，不需要 Node、yt-dlp 或配套电脑。
只支持能公开提供 H.264/AAC 流的视频。

## 使用前准备

- 设备需要联网、CA 证书、curl、FFmpeg、libmpv 和 AppKit 运行环境。
- 播放需要访问 YouTube、`i.ytimg.com` 和 `*.googlevideo.com`。
- 不支持登录、年龄限制、付费、DRM、直播清单或动态签名挑战内容。
- 播放使用默认 ALSA 音频输出；没有音频设备时画面仍可能运行。

## 搜索与推荐

1. 打开 **YouTube**，首页显示公开主题推荐。
2. 点击搜索，在 **Search YouTube** 输入关键词并提交。
3. 搜索页保留本次运行最近最多 12 条词，点击历史条目可再次搜索。
4. 点击结果卡片播放，推荐页使用 **Load more** 加载更多。
5. 关闭播放器回到原来的结果列表。

推荐来自轮换主题，不读取账号历史或订阅；缩略图在后台加载。

## 播放器与清晰度

播放器支持播放/暂停、失败重试、时间轴、前后 10 秒、音量与展开播放器。
状态会显示 `Opening video...`、`Buffering...`、`Finished` 或错误。
在播放器标题区选择 `1080p`、`720p`、`480p`、`360p` 或 `240p`；默认上限为 720p，实际值取决于公开视频流。

## 网络与数据

搜索、推荐、缩略图和流解析都会联网，不提供离线下载。
libmpv 的运行时缓冲不会出现在 Gallery 文件列表中。搜索词发送到 YouTube，缩略图使用 `i.ytimg.com`，播放通常来自 `googlevideo.com`。

管理员可设置 `LILYGO_YOUTUBE_DEBUG=1` 输出诊断，或设置 `LILYGO_YOUTUBE_TEST_MEDIA=/path/to/video.mp4` 做本地媒体验收；这些是启动变量，不是界面设置。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 搜索或推荐无法加载 | 检查网络、DNS、CA 证书和 YouTube/CDN 访问。 |
| 播放不支持 | 改用公开、非直播、非年龄限制、非 DRM 的 H.264/AAC 视频。 |
| 画面卡顿 | 降低清晰度上限并等待缓冲，检查带宽和解码能力。 |
| 缩略图不显示 | 缩略图服务可能受网络限制，不一定影响播放。 |
| 有画面无声音 | 检查默认 ALSA 输出、系统音量和音频设备。 |

当前没有账号、订阅、评论、收藏、下载、直播和 DRM 功能。
