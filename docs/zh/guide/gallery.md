# Gallery 相册使用说明

Gallery 浏览设备上的照片、相机 MP4 录像和截图，不需要联网。
它适合查看 [Camera](./camera) 的拍摄结果，也能显示手动复制到图片目录的文件。

## 使用前准备

- 安装 Gallery；视频播放需要设备提供 libmpv，图片解码需要相应运行库。
- 运行用户需要媒体文件的读取权限；删除和生成视频缩略图还需要目录写权限。
- 将文件直接放入下列目录，子目录不会被递归扫描。

| 来源 | 默认位置 |
| --- | --- |
| Camera | `$HOME/Camera`，也可跟随 `CAMERA_OUTPUT_DIR` |
| Pictures | `$HOME/Pictures` |
| Screenshots | `$HOME/screenshots` |

支持 JPEG、PNG、P6 PPM 和相机使用的 H.264 MP4；GIF 不会显示在相册中。
应用把各来源按文件修改时间合并，**整个相册最多保留最新 24 项**。
相簿数量仅反映这 24 项中的内容，并不是磁盘文件总数。

## 打开与浏览

1. 从启动器打开 **Gallery**，等待媒体网格加载。
2. 在 **Library** 中点击缩略图，打开照片或视频。
3. 用左右箭头、底部缩略图条或左右滑动切换当前集合中的项目。
4. 向下滑动或点击返回按钮，回到网格。
5. 新增文件后，点击页面顶部刷新图标重新扫描。

**Albums** 提供 `All Photos`、`Camera`、`Screenshots` 和 `Samples` 集合。
从相簿进入查看器后，左右切换只在该集合内进行。

## 查看照片与视频

- 照片查看器按完整画面适配，网格中的方形裁切不会改动原文件。
- 用 **+ / −** 以 25% 步长缩放照片；放大后拖动查看其他区域。
- 放大状态的滑动用于平移图片；缩小后再使用滑动切换或退出。
- 视频打开后自动播放；可暂停、继续、拖动时间轴和调节 0–100% 音量。
- 视频全屏按钮隐藏相册标题、详情操作和缩略图条；系统状态栏与主页指示仍可见。
- 离开视频查看器会停止播放。Camera 录制的视频没有音轨，因此调高音量也不会有声音。

## 查看详情与删除

向上滑动或点击详情图标，查看文件名、格式、尺寸、修改时间、大小、来源和路径。
视频还显示时长、编码和容器信息；详情内容可以滚动。

点击垃圾桶后，在确认面板选择 **Delete Item** 才会永久删除原文件；**Cancel** 可取消。
删除不是移入回收站；相关的相机或视频缩略图也会被尝试移除。
`Samples` 中的只读示例不能删除。安装包复制到 Pictures 的示例则是普通文件，可以删除。

## 自定义位置

管理员可以在启动前设置以下变量，应用内没有目录选择器：

| 变量 | 替换的来源 |
| --- | --- |
| `LILYGO_GALLERY_PHOTO_DIR` | Camera |
| `LILYGO_GALLERY_PICTURES_DIR` | Pictures |
| `LILYGO_GALLERY_SCREENSHOT_DIR` | Screenshots |
| `LILYGO_GALLERY_SAMPLE_DIR` | 只读 Samples |

环境变量更改后需重启应用。视频可能在同目录生成 `.thumb.rgb565` 缩略图文件。
尚未完成保存的 `.part.mp4` 不会显示，需等待 Camera 完成录制收尾。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 新照片不见了 | 刷新，核对运行用户、目录、文件格式及最新 24 项限制。 |
| 只看到示例图片 | 桌面模拟器在没有本地媒体时会使用内置样例；添加真实文件后刷新。 |
| 视频只有播放图标或无法播放 | 检查 MP4 是否已保存完整、编码是否受支持以及 libmpv 是否可用。 |
| 无法删除 | 查看确认面板中的错误，检查文件及目录权限；Samples 本身只读。 |
| 日期与拍摄日期不同 | 排序和详情使用文件修改时间，并不读取 EXIF 拍摄日期。 |
