# Calculator 计算器使用说明

Calculator 是触摸友好的科学计算器。竖屏为基础键盘，横屏增加科学函数。

## 基本计算

点击数字和小数点，选择 `+`、`-`、`*`、`/`、`%` 或 `^`，用括号组织表达式后按 `=`。
**AC** 清空新表达式，编辑中显示 **C**；Backspace/Delete 删除输入。表达式按标准优先级计算，
除零、定义域错误和溢出显示 `Error`。

## 科学功能

横屏提供 `2nd`、`sin`、`cos`、`tan`、`sinh`、`cosh`、`tanh`、`log`、`ln`、乘方、开方、
阶乘、绝对值、`e`、`pi`、`Rand` 和 `EE`。`2nd` 切换反函数，`Rad` / `Deg` 选择角度单位。
旋转会保留表达式、模式和记忆。

## 记忆与键盘

`mc` 清除，`m+` 加上，`m-` 减去，`mr` 取回。记忆只在当前进程有效，不是系统剪贴板。
模拟器和 TCA8418 支持数字、运算、括号、`=`、`C`、Backspace/Delete；方向键移动焦点，
`Tab` 前进，`Enter` 激活。

表达式、角度和记忆为进程内数据，不提供历史页或持久记录。

| 现象 | 检查 |
| --- | --- |
| `Error` | 除零、定义域、括号和溢出。 |
| 三角函数错误 | 检查 `Rad` / `Deg`。 |
| 按键无反应 | 按 `Tab` 或使用触摸。 |
| 键盘拥挤 | 旋转到横屏。 |



## 补充说明

旋转屏幕时显示状态会保留。`Rand` 按下时生成随机值，不保存随机序列；未定义科学表达式显示
`Error`。当前没有单位换算、图形、历史或导出页面，也没有专用剪贴板控件。
