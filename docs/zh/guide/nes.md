# NES 模拟器使用说明

NES 使用 FCEUmm 内核运行用户提供的 `.nes` 游戏文件，支持触屏、P1 键盘控制和本地存档。
游戏无需联网；应用不附带商业游戏 ROM，也不提供下载入口。

## 使用前准备

- 安装 NES，准备可使用的、未压缩的 `.nes` 文件。
- 启动用户的 `HOME` 必须是非空的绝对路径，且可创建 ROM 和存档目录。
- 设备声音使用 ALSA 默认输出，需要 alsa-utils 中的 aplay；模拟器使用 SDL2 音频。
- 多点触控组合按键需要触屏输入节点可读；普通鼠标只能提供单点操作。

## 导入和启动游戏

1. 从启动器打开 **NES**。首次启动会创建 `$HOME/nes/rom`。
2. 滚动到游戏列表最后一项 **Add ROM**，进入文件浏览器。
3. 浏览目录并点击 `.nes` 文件，应用会校验并复制到 ROM 目录，保留源文件。
4. 返回游戏库后，点击游戏行启动，使用方向键、A、B、Select 和 Start 游玩。
5. 点击 **Stop** 结束当前游戏并返回游戏库；它不是暂停按钮。

也可直接把 ROM 复制到 `$HOME/nes/rom` 后点击 **Refresh**。
扫描不递归且最多 128 项；同名文件不会在导入时被覆盖。
旧的 `$HOME/nes` 等位置不会自动迁移，需用 Add ROM 导入或手动移动。
把 ZIP 改名为 `.nes` 并不能转换为可用 ROM。

## 键盘控制

| 动作 | 默认按键 |
| --- | --- |
| 上 / 下 / 左 / 右 | W / S / A / D |
| A / B | K / J |
| 连发 A / 连发 B | I / U |
| Start / Select | 1 / 2 |

在游戏库底部打开 **Settings**，点击动作行，再按希望使用的新按键。
已分配给其他动作的按键会被拒绝；更改会立即保存。
当前不支持 P2 或实体游戏手柄，也没有游戏内暂停、重置、回退功能。

## 保存和恢复进度

游戏中点击 **Save** 保存当前时刻，点击 **Load** 恢复该游戏的上一次手动存档。
每个 ROM 只有一个手动存档，再次 Save 会替换它；启动游戏时不会自动 Load。
查看游戏页状态条确认保存或读取完成，错误时按提示检查文件或权限。

| 内容 | `game.nes` 的默认路径 |
| --- | --- |
| ROM | `$HOME/nes/rom/game.nes` |
| 手动存档 | `$HOME/nes/states/game.nes.state` |
| 电池存档 | `$HOME/nes/states/game.nes.sav` |

支持电池存储的游戏在正常 Stop 时写入电池存档；断电或强制退出可能丢失本轮进度。
备份或替换存档前先停止游戏。Add ROM 只导入 ROM，不自动导入存档。
手动存档与应用内核相关，不保证能与其他模拟器或未来内核版本交换。

## 删除和查找数据

向左滑动游戏行露出 **Delete**；点击后**立即永久删除 ROM，没有确认框或回收站**。
向右滑动可收起操作。删除 ROM 会保留 `.state` 和 `.sav` 存档。

底部 **Help** 显示实际展开后的 ROM、存档目录和操作说明，**Back** 返回游戏库。
键位保存在 `$XDG_CONFIG_HOME/lilygo-ui-nes/keymap.conf`，默认回退至 `$HOME/.config/lilygo-ui-nes/keymap.conf`。
不同系统用户的 ROM、存档与设置互不相同；例如 root 使用 `/root/nes/rom`。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 列表只有 Add ROM | 检查实际 HOME、ROM 目录、扩展名、读取权限及 128 项限制，然后刷新。 |
| 导入失败 | 检查文件是否未压缩、iNES 头是否有效、有无同名文件及目录写权限。 |
| 方向与 A/B 不能同时按 | 检查多点触控节点和权限；管理员可调整 `NES_TOUCH_DEVICE` 与 AppKit 的 `--input`。 |
| 游戏黑屏或无法运行 | 通过 iNES 头检查不代表兼容，需检查 ROM 完整性和 FCEUmm 对该游戏的支持。 |
| 没有声音 | 检查系统混音器、默认 ALSA 输出和 aplay；应用内没有音量或声卡选择器。 |
| Load 失败 | 检查存档是否存在、匹配该 ROM，且未损坏；不同内核的存档可能不兼容。 |
