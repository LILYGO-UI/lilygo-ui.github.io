# Camera 相机使用说明

Camera 使用设备上的摄像头拍摄 JPEG 照片和 H.264 MP4 视频。
本文对应已安装的应用；桌面模拟器只生成模拟画面，不会调用电脑摄像头。

## 使用前准备

- 使用已配置 Sony IMX219 摄像头的 T-DisplayCM0 系统，确认排线连接可靠。
- 设备需具备匹配的 libcamera、libcamera-ipa、FFmpeg 和 AppKit 运行环境。
- 启动应用的用户需要相机、显示和输入设备访问权限，以及保存目录的写权限。
- 关闭其他正在占用摄像头的程序，并留出足够的存储空间。
- 拍摄本地照片和视频不需要联网。

## 拍第一张照片

1. 从启动器打开 **Camera**，等待取景画面出现。
2. 选择 **Photo** 模式。
3. 调整构图；需要时打开网格，或切换 **1× / 2×** 数字裁剪。
4. 点击中央快门按钮，等待保存完成。
5. 点击快门旁的最新缩略图，查看本次启动后最近一次拍摄的预览和文件名。

最新缩略图来自低分辨率取景画面，并非原始照片查看器。
要查看完整照片或以前的拍摄内容，请打开 [Gallery 相册](./gallery)。

## 录制视频

1. 切换到 **Video**。
2. 点击快门开始录制，界面会显示录制计时。
3. 再次点击快门停止，等待 `Saving video…` 完成后再退出。
4. 在 Gallery 中打开保存的 MP4，或使用设备上的其他播放器。

当前录像**不录音**。Camera 内的最近拍摄预览也不能播放视频。

## 画质与构图

点击取景区顶部画质控件，依次切换以下请求配置：

| 标签 | 横向保存尺寸 | 请求帧率 |
| --- | --- | --- |
| `720P · 30` | 1280 × 720 | 30 fps |
| `1080P · 30` | 1920 × 1080 | 30 fps |
| `720P · 60` | 1280 × 720 | 60 fps |

竖屏保存时宽高相应交换。照片和视频共用所选配置。
每次启动恢复 `720P · 30`；切换失败时会显示错误并尝试恢复之前的配置。
60 fps 是请求值，实际帧率取决于传感器模式、系统和编码器。
2× 是数字裁剪，会影响取景和保存结果，不是光学变焦。

## 文件保存在哪里

默认保存在运行用户的 `$HOME/Camera`。关闭应用后，照片和视频仍保留在磁盘。
管理员可在启动进程前设置 `CAMERA_OUTPUT_DIR` 指向其他可写目录。
这属于启动环境配置，应用中没有目录选择菜单。

Camera 的最近拍摄预览只保留在本次会话内。模拟文件以 `SIM_IMG_` 或 `SIM_VID_` 开头。
若使用自定义目录，Gallery 也需使用相同的 `CAMERA_OUTPUT_DIR`，或设置其 `LILYGO_GALLERY_PHOTO_DIR`。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `Camera unavailable` 或没有预览 | 检查摄像头连接、系统摄像头配置、设备权限，并关闭其他相机程序。 |
| `Simulated preview` | 当前使用模拟后端；实机应使用真实相机配置，必要时由管理员检查 `CAMERA_SIMULATE=0`。 |
| 照片或视频保存失败 | 检查目录写权限、剩余空间、FFmpeg 是否可用。 |
| 选择 60 fps 后不流畅 | 换回 `720P · 30`；高帧率并非所有系统和传感器模式都能实现。 |
| 视频没有声音 | 当前版本只录制无声视频。 |
| 自动对焦无效 | 仅在摄像头栈提供 `AfMode` 时启用；有镜头马达不等于系统支持自动对焦。 |

当前没有切换摄像头、闪光灯、人像效果或音频录制功能。
