# Radio 网络电台使用说明

Radio 使用 Radio Browser 目录发现网络电台，也可播放自定义 HTTP/HTTPS 音频流。
收藏与台标可以保存在设备上，电台音频仍需联网实时播放。

## 使用前准备

- 安装 Radio，并确保设备可以访问网络和电台的音频服务器。
- Linux/CM0 需要 curl、FFmpeg、alsa-utils 中的 aplay 和可用的默认 ALSA 输出。
- macOS 模拟器使用 FFmpeg 和 ffplay；只有 ffmpeg 而没有 ffplay 时不能输出声音。
- 保存收藏和台标需要配置目录与缓存目录可写。

## 选择并收听电台

1. 从启动器打开 **Radio**，进入 **Stations**。
2. 等待热门电台加载，或在 **Search stations** 输入电台名称并搜索。
3. 点击一个电台开始播放；进入 **Playing** 查看完整播放器。
4. 使用播放、暂停、继续与停止控件控制收听。
5. 返回 Stations 或其他标签时，已选电台的迷你播放器仍可控制播放。

目录按每页 50 条请求；底部 **Load more stations** 加载后续结果。
刷新、搜索和浏览目录不会中断当前正在播放的电台。
首次目录加载成功前，可能看到内置 SomaFM 电台；这些同样需要网络。

## 收藏电台

点击播放器中的收藏控件保存或移除当前电台，随后在 **Favorites** 中访问。
最多保存 256 个完整电台记录，重启后仍可读取。
目录服务不可用时可以尝试播放已收藏的地址，但音频源本身仍需可访问。
台标一般是电台标志，不是当前歌曲的专辑封面。

## 播放自己的地址

1. 打开 **Settings**，选择 **Add a stream**。
2. 输入完整 `http://` 或 `https://` 音频地址。
3. 点击 **Play**；若输入不合法，按对话框的错误提示修正。
4. 使用 **Cancel** 放弃输入。

地址应指向可被 FFmpeg 解码的音频流，不是普通网页地址。
最近一次通过校验的地址会保存，之后预填在对话框中，但不会自动播放。

## 睡眠计时器

在 **Playing** 的计时入口，或 **Settings → Sleep Timer** 中设置 15、30、45、60 或 90 分钟。
倒计时结束时停止播放。重新选择时长会从当前时刻重新计时。
暂停、继续和换台不改变已有截止时间；取消计时不会停止音乐。
手动停止播放会同时取消计时；关闭应用后计时状态不会保存。

## 本地数据与网络请求

| 数据 | 默认位置 |
| --- | --- |
| 自定义地址 | `$HOME/.config/lilygo/ui/radio.conf` |
| 收藏 | 同一配置文件后追加 `.favorites` |
| 台标缓存 | `$HOME/.cache/lilygo/ui/radio-artwork` |
| 播放诊断 | `/tmp/lilygo-ui-radio.log` |

设置了 XDG 配置/缓存目录时，会使用对应 XDG 根目录。
管理员可用 `LILYGO_UI_RADIO_CONFIG` 指定配置文件，用 `LILYGO_UI_RADIO_ARTWORK_CACHE` 指定台标缓存。
将台标缓存变量设为空字符串可禁用磁盘台标缓存；应用没有清缓存按钮。
搜索词会发给 Radio Browser，音频和台标分别访问电台提供的服务器。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 目录无法加载 | 检查网络、curl 和证书；也可尝试已有收藏或自定义音频地址。 |
| 显示 Playing 但无声 | 此状态仅说明播放进程仍在运行；检查系统音量、默认输出和播放日志。 |
| 自定义流无法播放 | 确认地址是音频流、服务可访问且编码受 FFmpeg 支持。 |
| 收藏保存失败 | 查看储存错误，检查配置目录权限及磁盘空间。 |
| 没有台标 | 缺失或下载失败会显示默认图标，不影响音频；检查 FFmpeg 和台标主机。 |

应用不缓存节目音频供离线收听，也没有离线电台模式。
